<h2>Descripción de LaKArta</h2>

<p>Aplicación para ver menús, realizar pedidos y dejar valoraciones en restaurantes.</p>

<p>Panel de administración para que los restaurantes gestionen sus menús y fotos.</p>

<h3>Tecnologías utilizadas</h3>

    Lenguaje: Java (Android)
    Frameworks y Librerías: Glide (carga de imágenes), Retrofit/Volley (API REST), Google Maps API
    Base de Datos: MySQL (gestionada con phpMyAdmin)
    Backend: PHP (API REST propia para autenticación y gestión de datos)
    Autenticación: Sistema de login personalizado en PHP (JWT/Sesiones)
    Carga de imágenes: Glide/Picasso
    Gestión de pedidos y valoraciones: API REST con MySQL

<h3>Principales funciones implementadas</h3>

✅ Autenticación personalizada en PHP para usuarios y restaurantes.

✅ Sistema de pedidos con seguimiento en tiempo real.

✅ Carga y visualización de menús con imágenes optimizadas mediante Glide.

✅ Gestión de restaurantes: creación de menús personalizados con fotos y descripciones.

✅ Sistema de comentarios y valoraciones para evaluar restaurantes y menús.

✅ Consumo de API REST para la sincronización de datos entre la app y la base de datos MySQL.

✅ Optimización de consultas en MySQL para mejorar el rendimiento de la app.
